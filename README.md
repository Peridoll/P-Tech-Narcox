# P-Tech Narcox

FiveMロールプレイサーバー向けの架空植物・ドラッグ関連ゲームシステム群です。

リソースは `ptech_narcox_<module>` 形式で個別に導入できるように開発します。

リポジトリ内では `resources/[ptech]/[narcox]/` に配置しています。

## 現在の状態

開発・検証中。現在のリソースは次の2つです。

- `ptech_narcox_foraging`：野生タンポポの採取。
- `ptech_narcox_contracts`：NPCごとのランダム調達依頼、複数同時受注、期限、好感度と依頼開放。

タンポポは実在の植物とは異なる架空植物です。Eキーで採取し、20分後に同じエリアの別候補地点へ再出現します。

Contractsの最初の依頼は、手持ちのタンポポの花も使える調達です。依頼主へ戻って納品すると銀行口座へ即時振込されます。ログアウト中・サーバー停止中は制限時間が止まります。

Contractsの配置・経済数値は仮設定です。導入時に調整して `Config.Enabled = true` にしてください。将来の加工依頼・売人・市場相場は未実装です。

**FiveM実機未検証**です。導入手順と詳細な実装・検証状況は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
